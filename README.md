Khalid House (دار خالد) - Coffee Shop Website
A modern, responsive, and bilingual (English/Arabic) landing page for Khalid House, a premium coffee destination established in 2020. This project showcases a clean UI with smooth navigation and a cozy aesthetic tailored for coffee lovers.

☕ Project Overview
This website serves as a digital storefront for Khalid House, providing customers with information about our coffee selection, desserts, and physical locations in Riyadh and Al Khobar. The design focuses on high-quality imagery and a warm color palette to reflect the café's atmosphere.

✨ Features
Bilingual Interface: Fully supports both English and Arabic text content.

Responsive Design: Optimized for all devices, including desktops, tablets, and mobile phones.

Interactive Navigation: A sticky header with a mobile-specific toggle menu for easy browsing.

Dynamic Menu: Categorized sections for Hot Drinks, Cold Drinks, Fresh Juices, Special Drinks, Desserts, and Ice Cream.

Image Gallery: A visually appealing grid layout with hover-zoom effects to showcase the café's ambiance.

Contact & Location: Integrated contact form and clear operational hours for multiple branches.

Smooth Scrolling: Enhanced user experience with seamless transitions between sections.

🛠️ Technologies Used
HTML5: Structured the content and bilingual text.

CSS3: Custom styling using CSS Variables for easy theme management and Flexbox for layout.

JavaScript (ES6): Handled mobile menu logic and UI interactions.

Font Awesome: High-quality icons for social media and contact details.

Google Fonts: Specialized typography (Poppins and Miniver) for a premium feel.

Swiper JS: (Integrated for future slider functionality/Gallery support).

📂 File Structure
index.html - The main structure of the website.

style.css - Custom styles, responsive media queries, and color variables.

script.js - Mobile menu functionality and library initializations.

/images - Directory containing coffee, menu, and gallery assets.

🚀 How to Run
Clone or download this repository.

Ensure you have an images/ folder with the necessary assets as referenced in the HTML.

Open index.html in any modern web browser.
